# ボスの参考情報とローカル計測（試験機能）

バトルHUDがボスを検出すると、設定画面に属性倍率や説明を表示します。HUD設定の「HUDにボスの弱点・耐性を表示する」で小窓内の表示を切り替えられます。データが見つからない場合は未登録と表示します。

形態別の表があるボスはログ上のボス名の `Phase` 番号で判定します。形態の情報がない共通表については、その情報を表示します。倍率はゲームの更新などで変わる場合があるため、参考情報として扱ってください。

弱点・耐性データ `boss_weakness_data.txt` は [EclipticaHUD-C](https://github.com/WntSnwf/EclipticaHUD-C) の MIT ライセンスの表を使用しています。著作権表示とライセンス文は `LICENSE_EclipticaHUD-C.txt` に同梱しています。

公開されているログ形式を参考に、自分の `Dealing ... STRIKE/NON-STRIKE damage`、ボスの所有権変更、トークン出現・セッション保存を検出します。トークン出現数と取得数はステージ中の推定値です。休憩中の攻撃は練習ダミーとみなして別に計測し、次の場面に移ると直近記録として表示します。途中から監視を始めた場合、過去のダメージは現在の DPS に加算されません。実際のログ形式やワールドの更新により、検出できない場合や推定が外れる場合があります。

この機能はパーティーメンバー間の同期や、VRChat 内の落槌マーカーを追加するものではありません。
