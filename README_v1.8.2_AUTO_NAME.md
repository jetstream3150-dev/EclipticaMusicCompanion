# Ecliptica Music Companion v1.8.2 β Lite — VRChat表示名の自動取得

## 追加機能

- **バトルHUD →「VRChatログから自分の名前を自動取得する」**（標準でON）
- VRChatの最新 `output_log_*.txt` に書かれる `User Authenticated: 表示名 (usr_...)` を読み、HUDの名前欄を自動入力します。
- 15秒おきに最新のVRChatログを確認。アカウントの切り替えも新しい認証記録があれば反映します。
- 「↻ 今すぐ取得」で手動再読込が可能です。
- 取れないときは自動取得をOFFにして、以前と同じように手入力できます。
- 以前のv1.8.1で名前を手入力して保存していた場合、**手入力モードを維持**します。自動取得を希望する場合はチェックをONにしてください。
- 他人の `OnPlayerJoined` は自分の名前と判断しません。
- ログが古い、またはログイン成功の記録が見つからない場合は名前を推定せず、ターゲット通知の誤判定を避けます。
- ライブ戦闘イベントがHUDのDPS/ターゲット解析に送られない不具合を修正しました。

## 使い方

1. VRChatにログインし、VRChatのログを「完全」に設定します。
2. v1.8.2を起動し、**バトルHUD**タブを開きます。
3. 「VRChatログから自分の名前を自動取得する」をONにします。
4. 正しい表示名が自動表示されたら「HUDの設定を保存」を押してください。
5. 取得に失敗したら「↻ 今すぐ取得」を押すか、チェックをOFFにして手入力してください。

## プライバシー / 制限

- 読むのは手元のVRChatログのみ。VRChat認証情報やパスワードは不要で、名前取得用の外部通信もありません。
- ログの既知の認証書式が変更された場合、自動取得できなくなることがあります。
- 同じPCで複数アカウントを使用する場合、直近のログを基準にします。画面の表示名が正しいか確認してください。
- バトルHUDのターゲット/DPS検出は引き続き**試験版**。ログに該当イベントが出ない場合は通知できません。
- v1.8.1 Liteと同様にYouTubeのMP3への変換・ダウンロードは無効です。YouTube URLでの再生・手持ちのMP3登録は維持しています。
- 本ソースZIPはWindows EXEそのものではありません。GitHub Actionsで再ビルドしてください。
- セキュリティソフトの誤検知解消や、バイナリがマルウェアではないことを保証するものではありません。配布前に新しいビルドの検査をしてください。
