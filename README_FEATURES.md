# 追加機能の使い方（試験版）

## 曲の登録と診断

- 「曲を設定」または「ボスの曲」で保存・試聴すると、実際のプレーヤーから再生状態が返った場合に結果を表示します。YouTube のエラー 101 / 150 は埋め込み制限として表示します。プレーヤーが応答しない場合は未確認です。再生開始が確認されても、スピーカーから音が聞こえることまで保証するものではありません。
- 音源は各自のYouTube URLや音楽ファイルを設定してください。試用曲は付属しません。以前の内蔵曲が設定された欄は、別の曲に変更してください。
- ホームの「ワンタップ診断」で、接続・音量・ログ・監視・YouTubeプレーヤーを確認できます。Windowsのサウンド出力先や実際の音声は確認できません。
- 難易度別の画面では同じ場面の全難易度へ一括設定できます。一括設定は確認後に既存の曲を上書きします。保存・試聴によって現在の再生曲は切り替わります。YouTubeが再生できない場合は、設定した予備音源が使用されます。

## VRChatログと戦闘リザルト

- 開始時またはログ切り替え時に、直近のログから現在の場面を推定します。ログが古い・情報がない・ワールドから退出した場合、現在の場面は未確認です。次のイベントを待つか手動で試聴してください。
- ボス区間の終了・切り替え時に、観測時間と自分のログで確認したダメージから平均DPSを計算します。途中参加や監視停止時は部分集計です。勝敗は判断しません。同じボスの直近の記録がある場合、ダメージの前回比を表示します。
- リザルトは `%LOCALAPPDATA%\EclipticaMusicCompanion\battle_results.json` に最大100件を保存し、画面には直近20件を表示します。ログ本文や参加者の情報は保存・送信しません。不要な場合はアプリ終了後にこのファイルを削除できます。

## SteamVR HUD（試験機能）

- SteamVRを起動し、アプリの「バトルHUD」で「SteamVRヘッドセット内にHUDを表示する」をONにします。既存のデスクトップHUDとは別に設定できます。初期状態はOFFです。
- ボス名、DPS、ボスダメージ、推定ターゲットを視界の下寄りに表示します。SteamVRに接続できない場合は画面に状態を表示し、再接続を試みます。
- 「ヘッドセット内でもダメージとターゲットを別々に表示する」をONにすると、視界の左右に2つの独立したHUDを表示します。実機での位置やVRChatとの互換性は未検証です。
- デスクトップ用のダメージとターゲットはそれぞれ独立した最前面の小窓で表示します。各小窓は上端をドラッグして移動でき、右上の×で閉じられます。「バトルHUD」で個別に再表示できます。VRChatをウィンドウまたはボーダーレス表示でお試しください。排他フルスクリーンでは表示できない場合があります。

## 難易度別の自動再生

- ホームは「自動判定」が初期設定です。ステージやボスのログの進行度から難易度を推定し、対応するBGMに切り替えます。途中参加では現在のログを読み直します。休憩中は直前の判定を使用します。
- 判定区分は非公式なコミュニティの対応表に基づく推定で、ECLIPTICAの公式APIによる保証ではありません。判定できない場合、難易度別の曲は停止し、画面に待機中と表示します。必要ならホームで手動選択できます。試聴で選んだ難易度は自動再生に影響しません。
- 推定の参考： [MINMAXXER のログ説明](https://github.com/kittynXR/MINMAXXER/blob/50638815a34113f703260d68ae01e7a3f9fef06c/docs/LOG_TELEMETRY.md)、[ECLIPTICA Advanced Combat Tracker のフェーズ説明](https://eact-doc.rtail.dev/?lang=ja#phases)。`1.0` は終盤の Bringer のステージまたはボスを確認した場合のみ Eye of the Eclipse とし、判別できない終盤の再通知は推測しません。
- 自動判定にはVRChatのログにECLIPTICAのイベントが出る必要があります。表示が「ログを待っています」のままなら、VRChatの設定や起動オプションを確認してください。ログを増やす設定は容量や性能に影響する場合があります。
- ボス専用の曲が登録されている場合は、難易度別のボス曲より優先されます。別の曲にしたい場合は各難易度に登録してください。
- ヘッドセット実機での見え方や各VR環境での互換性は未確認です。ターゲットは推定であり、戦闘中の安全を保証しません。
- 個人情報や生ログを外部へ送信しません。パーティー共有は別機能で、接続した場合の注意は画面に記載しています。
