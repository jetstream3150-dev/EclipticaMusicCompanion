# 追加機能の使い方（試験版）

## 曲の登録と診断

- 「曲を設定」または「ボスの曲」で保存・試聴すると、実際のプレーヤーから再生状態が返った場合に結果を表示します。YouTube のエラー 101 / 150 は埋め込み制限として表示します。プレーヤーが応答しない場合は未確認です。再生開始が確認されても、スピーカーから音が聞こえることまで保証するものではありません。
- 「内蔵の試用曲」はオリジナルの短いループです。難易度別の画面では同じ場面の全難易度へ一括設定できます。一括設定は確認後に既存の曲を上書きします。
- ホームの「ワンタップ診断」で、接続・音量・ログ・監視・YouTubeプレーヤーを確認できます。Windowsのサウンド出力先や実際の音声は確認できません。
- プリセットの「この曲を入力」を押すと、選択中の枠の曲が自動保存されます。ほかの難易度やボスの設定は、一括設定を確認した場合を除き変更しません。保存・試聴によって現在の再生曲は切り替わります。

## VRChatログと戦闘リザルト

- 開始時またはログ切り替え時に、直近のログから現在の場面を推定します。ログが古い・情報がない・ワールドから退出した場合、現在の場面は未確認です。次のイベントを待つか手動で試聴してください。
- ボス区間の終了・切り替え時に、観測時間と自分のログで確認したダメージから平均DPSを計算します。途中参加や監視停止時は部分集計です。勝敗は判断しません。同じボスの直近の記録がある場合、ダメージの前回比を表示します。
- リザルトは `%LOCALAPPDATA%\EclipticaMusicCompanion\battle_results.json` に最大100件を保存し、画面には直近20件を表示します。ログ本文や参加者の情報は保存・送信しません。不要な場合はアプリ終了後にこのファイルを削除できます。

## SteamVR HUD（試験機能）

- SteamVRを起動し、アプリの「バトルHUD」で「SteamVRヘッドセット内にHUDを表示する」をONにします。既存のデスクトップHUDとは別に設定できます。初期状態はOFFです。
- ボス名、DPS、ボスダメージ、推定ターゲットを視界の下寄りに表示します。SteamVRに接続できない場合は画面に状態を表示し、再接続を試みます。
- ヘッドセット実機での見え方や各VR環境での互換性は未確認です。ターゲットは推定であり、戦闘中の安全を保証しません。
- 個人情報や生ログを外部へ送信しません。パーティー共有は別機能で、接続した場合の注意は画面に記載しています。
